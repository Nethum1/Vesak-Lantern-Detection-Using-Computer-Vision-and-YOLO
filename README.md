# Vesak-Lantern-Detection-Using-Computer-Vision-and-YOLO
Developed a computer vision-based object detection system to automatically identify Vesak lanterns in images using a custom-trained YOLO model. The project involved building a complete machine learning pipeline, starting with image collection and dataset preparation.

A custom dataset was created by collecting Vesak lantern images with different shapes, colors, sizes, backgrounds, lighting conditions, and viewing angles. The images were annotated using CVAT (Computer Vision Annotation Tool), where bounding boxes were drawn around each Vesak lantern and assigned to the “Lantern” class. The annotated dataset was then exported in YOLO format and organized for model training and evaluation.
